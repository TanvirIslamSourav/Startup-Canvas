# Internationalization

> Default: **বাংলা (bn)** · Secondary: **English (en)**

---

## 1. Library

`react-i18next` + `i18next-browser-languagedetector`. Locales are bundled (no network fetch) for offline use.

## 2. Files

```
frontend/src/i18n/
├── index.ts                # init()
├── locales/
│   ├── bn.json
│   └── en.json
└── types.ts                # generated key types (optional)
```

## 3. Key conventions

- Dotted namespaces by feature: `ideas.list.empty`, `dashboard.cards.total_ideas`.
- Pluralization: `_one`, `_other`, `_many` suffixes.
- Interpolation: `"{{count}}টি আইডিয়া" : "{{count}} idea"`.
- No raw user input inside translations (XSS‑proof).

## 4. Adding a new key

1. Add the key to **both** `bn.json` and `en.json` in the same PR.
2. Use it via `const { t } = useTranslation(); t('ideas.list.empty')`.
3. CI fails the build if a key is missing in either locale.

## 5. Switching language

- Settings → Language selector.
- Persists to `localStorage['i18nextLng']`.
- On boot, `i18n/index.ts` reads localStorage and falls back to `bn`.
- Backend user record's `locale` field is the source of truth across devices once auth lands.

## 6. Bangla typography

- Primary font: **Noto Sans Bengali** (Google Fonts, embedded).
- Code/numbers: **JetBrains Mono** (Latin only).
- Line height 1.6 for body, 1.3 for headings.

## 7. RTL

Not needed for Bangla (LTR script). If Arabic/Hebrew are added later, `dir="rtl"` toggling is centralized in `theme/tokens.css`.
